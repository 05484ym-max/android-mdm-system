# Android MDM System

מערכת MDM (Mobile Device Management) חינמית וקוד פתוח לניהול מכשירי Android מרחוק.

## מבנה הפרויקט
- `dpc-app/` — אפליקציית Android Device Policy Controller (DPC)
- `backend/` — שרת API לניהול מכשירים, מדיניות ופקודות
- `admin-panel/` — פאנל ניהול Web למנהל המערכת
- `docs/` — תיעוד ארכיטקטורה והחלטות

## מכשיר בדיקה
Samsung Galaxy A31, Android 12, One UI 4.1
